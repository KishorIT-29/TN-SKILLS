# TN Skills Portal - GitHub Pages Deployment Guide

This repository contains the **TN Skills User Login Portal & Candidate Hall Ticket Dashboard** (`index.html`).

## How to Deploy on GitHub Pages

1. Extract this ZIP archive so you have `index.html` ready on your computer.
2. Create a new **Public** repository on [GitHub](https://github.com/new) (e.g., `tn-skills-portal`).
3. Upload `index.html` (and optionally `README.md`) into the root of your repository and commit the changes.
4. Go to your repository's **Settings** -> **Pages**.
5. Under **Build and deployment** -> **Branch**, select **`main`** and folder **`/ (root)`**, then click **Save**.
6. Wait 1-2 minutes and refresh the page to get your live GitHub Pages URL:
   `https://<your-username>.github.io/tn-skills-portal/`
